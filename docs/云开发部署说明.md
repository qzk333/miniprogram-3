# 校园借借 — 微信云开发部署说明

本次「必做功能」**未新增云函数**，仍使用项目原有的 `login`、`sendEmail`。前端直连云数据库读写 `comments` 集合及扩展后的 `items` / `orders` 字段。

## 一、环境准备

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 用管理员微信扫码登录，导入本项目目录
3. 确认 `miniprogram/app.js` 中的云环境 ID 与控制台一致（当前为 `cloud1-0gaxhtt078d18f40`）
4. 在开发者工具顶部选择：**云开发** → 开通环境（若尚未开通）

## 二、云数据库集合

在云开发控制台 → **数据库** 中创建或确认以下集合：

| 集合名 | 说明 | 本次是否新增 |
|--------|------|----------------|
| `users` | 用户资料、认证状态 | 已有 |
| `items` | 租借物品 | 已有（字段扩展见下） |
| `orders` | 预约订单 | 已有（字段扩展见下） |
| `comments` | 物品评论区 | **需新建** |

### 2.1 `items` 新增字段（无需迁移，新发布自动带上）

- `description`：物品说明（字符串，可选）
- `contactWechat`：微信号（可选）
- `contactQQ`：QQ 号（可选）

### 2.2 `orders` 新增字段

- `publisherOpenid`：出借方 openid（新订单自动写入）
- `rentDays`：借用天数（可选，便于展示）

### 2.3 `comments` 集合结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `itemId` | string | 对应 `items._id` |
| `content` | string | 评论内容，最长 200 字 |
| `authorOpenid` | string | 评论者 openid |
| `authorNickname` | string | 评论者昵称快照 |
| `createTime` | date | 服务器时间 |

### 2.4 数据库索引（重要）

在 `comments` 集合 → **索引** 中添加：

- 组合索引：`itemId`（升序）+ `createTime`（降序）

否则详情页按时间排序查询可能报错或很慢。

`orders` 若「收到的预约」列表较慢，可为 `publisherOpenid` + `createTime` 建组合索引（可选）。

### 2.5 数据库权限（开发期建议）

课程演示可在开发阶段使用较宽松规则，答辩前再收紧：

| 集合 | 建议（开发） |
|------|----------------|
| `items` | 所有用户可读；仅创建者可写自己的文档 |
| `orders` | 所有用户可读；登录用户可写（与现有逻辑一致） |
| `comments` | 所有用户可读；仅创建者可写、可删自己的评论 |
| `users` | 仅创建者可读写自己的文档 |

控制台路径：**云开发 → 数据库 → 集合 → 权限设置**。

## 三、云函数

### 已有云函数（需上传部署）

| 云函数 | 作用 |
|--------|------|
| `login` | 获取用户 openid |
| `sendEmail` | 发送校园邮箱验证码 |

**部署步骤：**

1. 在开发者工具左侧展开 `cloudfunctions` 目录
2. 右键 `login` → **上传并部署：云端安装依赖**
3. 右键 `sendEmail` → 同上（需先在云函数环境变量中配置邮箱，见下）

### `sendEmail` 环境变量（推荐）

勿将 QQ 邮箱授权码提交 Git。在云开发控制台 → **云函数** → `sendEmail` → **配置** → 环境变量：

- `SMTP_USER`：发件邮箱
- `SMTP_PASS`：SMTP 授权码

（若代码仍使用硬编码，需在后续改为读取环境变量。）

### 本次未创建的云函数

支付相关 `createPayment` / `payNotify` 等**尚未实现**，不在本次部署范围。

## 四、云存储

用于物品图片、头像、面交/归还凭证，一般开通云开发后自动可用。

确认 **存储权限** 允许已登录用户上传（默认即可）。

路径约定：

- `items/` — 物品主图
- `avatars/` — 用户头像
- 订单凭证由 `order` 页面上传（现有逻辑）

## 六、功能自测路径

1. **我的** → 微信登录 → 发布物品（填写说明、微信/QQ）
2. 另一账号或模拟器 → 首页进入详情 → 复制联系方式、发表评论
3. 选择日期预约 → **我的** → **收到的预约**（出借方可见）
4. 详情页选择日期后应显示约计租金
