# 校园借借 — 微信云开发部署说明

本次「必做功能」**未新增云函数**，仍使用项目原有的 `login`、`sendEmail`。前端直连云数据库读写 `comments` 集合及扩展后的 `items` / `orders` 字段。

## 一、环境准备

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 用管理员微信扫码登录，导入本项目目录
3. 确认 `miniprogram/app.js` 中的云环境 ID 与控制台一致（当前为 `cloud1-0gaxhtt078d18f40`）
4. 在开发者工具顶部选择：**云开发** → 开通环境（若尚未开通）

## 二、云数据库集合

在云开发控制台 → **数据库** 中创建或确认以下集合：

| 集合名 | 说明 | 本次是否新增 |
|--------|------|----------------|
| `users` | 用户资料、认证状态 | 已有 |
| `items` | 租借物品 | 已有（字段扩展见下） |
| `orders` | 预约订单 | 已有（字段扩展见下） |
| `comments` | 物品评论区 | **需新建** |
| `notifications` | 收到的私信通知 | **需新建** |

### 2.1 `items` 新增字段（无需迁移，新发布自动带上）

- `description`：物品说明（字符串，可选）
- `contactWechat`：微信号（可选）
- `contactQQ`：QQ 号（可选）

### 2.2 `orders` 新增字段

- `publisherOpenid`：出借方 openid（新订单自动写入）
- `rentDays`：借用天数（可选，便于展示）
- `rentTotal`：租金合计（元，预约时写入）
- `payStatus`：`unpaid` / `paid` / `settled`（账本托管状态）
- `payMode`：`mock` / `offline` / `wxpay`（支付渠道，演示默认为 `mock`）
- `paidAt` / `settledAt`：支付与结算时间
- `borrowerHandoverOk` / `publisherHandoverOk`：面交双方确认
- `borrowerReturnOk` / `publisherReturnOk`：归还双方确认

### 2.3 `comments` 集合结构

| `itemId` | string | 对应 `items._id` |
| `content` | string | 评论内容，最长 200 字 |
| `authorOpenid` | string | 评论者 openid |
| `authorNickname` | string | 评论者昵称快照 |
| `replyToId` | string | 可选，顶层评论 `_id`（回复时写入） |
| `replyToNickname` | string | 可选，被回复者昵称 |
| `replyToOpenid` | string | 可选，被回复者 openid（用于私信通知） |
| `createTime` | date | 服务器时间 |

### 2.3.1 `notifications` 集合结构（收到的私信）

| 字段 | 类型 | 说明 |
|------|------|------|
| `recipientOpenid` | string | 接收者 openid |
| `type` | string | `item_comment` / `item_reply` / `reply` / `order_new` / `order_accepted` / `order_rejected` |
| `orderId` | string | 可选，预约相关通知关联订单 |
| `itemId` | string | 关联物品 |
| `itemTitle` | string | 物品标题快照 |
| `commentId` | string | 触发通知的评论 id |
| `content` | string | 内容摘要 |
| `fromOpenid` | string | 发送者 openid |
| `fromNickname` | string | 发送者昵称 |
| `isRead` | boolean | 是否已读 |
| `createTime` | date | 服务器时间 |

### 2.4 数据库索引

路径：**云开发控制台 → 数据库 → 选中集合 → 索引 → 添加**。

需填写两项：**索引名称**（自定义英文，同集合内不重复即可）、**索引字段**（字段名 + 升序/降序）。  
索引属性选 **非唯一**（不要勾选「唯一索引」），除非特别说明。

#### `notifications`（必建，私信列表与未读数）

| 索引名称 | 索引字段 | 对应功能 |
|----------|----------|----------|
| `idx_recipient_createTime` | `recipientOpenid` 升序，`createTime` **降序** | 收到的私信列表 |
| `idx_recipient_isRead` | `recipientOpenid` 升序，`isRead` 升序 | 未读数量统计 |

#### `comments`（必建，否则评论列表易报错）

| 索引名称 | 索引字段（按顺序添加） | 对应代码查询 |
|----------|------------------------|--------------|
| `idx_itemId_createTime` | `itemId` 升序，`createTime` **降序** | 详情页 `where({ itemId }).orderBy('createTime', 'desc')` |

#### `orders`（建议建，列表更稳）

| 索引名称 | 索引字段 | 对应功能 |
|----------|----------|----------|
| `idx_borrower_createTime` | `borrowerOpenid` 升序，`createTime` **降序** | 我的租借 |
| `idx_publisher_createTime` | `publisherOpenid` 升序，`createTime` **降序** | 收到的预约（含 `publisherOpenid` 条件时） |
| `idx_itemId` | `itemId` 升序（单字段） | 详情页日历占用 `where({ itemId })` |

说明：`收到的预约` 若使用 `itemId in [...]` 的兼容查询，单索引无法完全覆盖，但数据量小时可正常运行；有 `publisherOpenid` 的新订单会走第二条索引。

#### `items`（建议建）

| 索引名称 | 索引字段 | 对应功能 |
|----------|----------|----------|
| `idx_createTime` | `createTime` **降序**（单字段） | 首页全部物品 `orderBy('createTime', 'desc')` |
| `idx_publisher_createTime` | `publisherOpenid` 升序，`createTime` **降序** | 我的发布 |

#### `users`（一般不用建）

用户资料用 `doc(openid)` 按文档 ID 读取，系统对 `_id` 已有默认索引，**无需再添加组合索引**。

#### 控制台填写示例（以 `comments` 为例）

1. 索引名称：`idx_itemId_createTime`
2. 索引字段：点「添加」→ 字段名 `itemId`，排序 **升序**
3. 再点「添加」→ 字段名 `createTime`，排序 **降序**
4. 保存，等待索引状态变为「正常」后再测评论功能

### 2.5 数据库权限（开发期建议）

课程演示可在开发阶段使用较宽松规则，答辩前再收紧：

| 集合 | 建议（开发） |
|------|----------------|
| `items` | 所有用户可读；仅创建者可写自己的文档 |
| `orders` | 所有用户可读；登录用户可写（与现有逻辑一致） |
| `comments` | 所有用户可读；仅创建者可写、可删自己的评论 |
| `notifications` | 仅接收者可读；登录用户可写（评论时自动创建） |
| `users` | 仅创建者可读写自己的文档 |

控制台路径：**云开发 → 数据库 → 集合 → 权限设置**。

## 三、云函数

### 已有云函数（需上传部署）

| 云函数 | 作用 |
|--------|------|
| `login` | 获取用户 openid |
| `sendEmail` | 发送校园邮箱验证码 |
| `confirmPay` | 借方确认支付租金（账本托管，演示模式无需商户号） |
| `settleRent` | 订单完成后将租金标记为已结算给出借方 |
| `respondBooking` | 出借方接受/拒绝预约（`awaiting_confirm` → `pending` 或删除） |

**部署步骤：**

1. 在开发者工具左侧展开 `cloudfunctions` 目录
2. 右键 `login` → **上传并部署：云端安装依赖**
3. 右键 `sendEmail` → 同上（需先在云函数环境变量中配置邮箱，见下）
4. 右键 `confirmPay`、`settleRent`、`respondBooking` → **上传并部署：云端安装依赖**

### `sendEmail` 环境变量（推荐）

勿将 QQ 邮箱授权码提交 Git。在云开发控制台 → **云函数** → `sendEmail` → **配置** → 环境变量：

- `SMTP_USER`：发件邮箱
- `SMTP_PASS`：SMTP 授权码

（若代码仍使用硬编码，需在后续改为读取环境变量。）

### 真实微信支付（可选，未实现）

若日后申请商户号，可新增 `createPayment` / `payCallback` 对接 `cloudPay.unifiedOrder`；当前使用 `confirmPay` 账本托管 + `MOCK_PAY` 演示即可。

## 四、云存储

用于物品图片、头像、面交/归还凭证，一般开通云开发后自动可用。

确认 **存储权限** 允许已登录用户上传（默认即可）。

路径约定：

- `items/` — 物品主图
- `avatars/` — 用户头像
- 订单凭证由 `order` 页面上传（现有逻辑）

## 六、功能自测路径

1. **我的** → 微信登录 → 发布物品（填写说明、微信/QQ）
2. 另一账号或模拟器 → 首页进入详情 → 复制联系方式、发表评论
3. 选择日期预约 → **我的** → **收到的预约**（出借方可见）
4. 详情页选择日期后应显示约计租金
